# Content design

GOV.UK content style applies — these are the points worth pinning, plus how to adapt for this service's audience.

- Sentence case everywhere. No ampersands.
- ISO-style dates: "24 April 2025".
- Active voice. Address the user as "you". One idea per sentence. Front-load the key information.
- Lead with the user's goal, not the system's action.
- Error messages: say what happened and what to do next.

## Adapting to audience

This service's audience is set in `project.md`.

- **Internal**: departmental terminology and acronyms are fine, copy can be more concise and more formal, and you can assume familiarity with the relevant processes. Optimise for getting the task done, not for explaining the domain.
- **Public**: plain language, no assumed knowledge, expand acronyms on first use, and give more guidance.

When creating or refining any user-facing copy — headings, labels, button text, errors, microcopy — prefer the `gov-content-designer` sub-agent so it's right from the start rather than retrofitted.
